# EmbedEarth documentation

EmbedEarth is an open, programmable geographic layer for physical-world data.
Start with the interface you use—[SDK](sdk.md), [CLI](cli.md), or [MCP](mcp.md)—then
move through the same core areas:

1. [Search](search.md) — return matching geographic records.
2. [Spatial compute](compute.md) — measure relationships and aggregates.
3. [Routes](routes.md) — build journeys, matrices, and reachable areas.
4. [Maps](maps.md) — render Planet and feature layers in MapLibre.
5. Stratum — look up features and areas, pull server data, cache it, query locally, and upload local data.

Cloud mode can be used without a key, but unauthenticated access is heavily
limited. Add an API key from [embed.earth](https://embed.earth) for unlimited
Search and Compute and for Street View image access.
