# Roadmap

Broad milestones for the EmbedEarth developer platform. Dates are intentionally omitted while the repository is private.

## Core APIs

- Stable search, places, geocoding, and route contracts
- Consistent errors, pagination, and response metadata
- Browser-safe and Node.js SDK entry points

## SDKs and interfaces

- JavaScript/TypeScript SDK stabilization
- `earth` CLI with table, JSON, CSV, and GeoJSON output
- MCP tools for search, route, nearby, within, count, and visual search
- Python and DuckDB integration examples

## Maps and datasets

- MapLibre client with documented source and layer contracts
- Dataset registry with provenance, licensing, coverage, and refresh metadata
- More public examples for permits, incidents, infrastructure, and observations

## Developer experience

- Examples that run with one command
- API reference generated from public types
- Release notes and versioned migration guides
