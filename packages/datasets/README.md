# @embedearth/datasets

Snapshot index and downloader for published E2 datasets (immutable, compressed GeoParquet snapshots in object storage).

Part of **E2**, the open spacetime index for Earth. Most users should install
[`@embedearth/sdk`](https://www.npmjs.com/package/@embedearth/sdk) instead of
depending on this package directly.

## Install

```bash
npm install @embedearth/datasets
```

## Usage

```ts
import { loadSnapshotIndex } from "@embedearth/datasets";
```
