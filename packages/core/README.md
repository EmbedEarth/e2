# @embedearth/core

Spacetime cell encoding, decoding, and traversal — the core algebra behind E2, the open spacetime index for Earth. Combines H3 spatial cells with a deterministic temporal layer and an optional embedded feature id.

Part of **E2**, the open spacetime index for Earth. Most users should install
[`@embedearth/sdk`](https://www.npmjs.com/package/@embedearth/sdk) instead of
depending on this package directly.

## Install

```bash
npm install @embedearth/core
```

## Usage

```ts
import { encode, decode, spatialNeighbors } from "@embedearth/core";
```
