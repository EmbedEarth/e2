# @embedearth/regions

The E2 region catalog: countries, states, cities, and areas used to scope feature searches and local computation.

Part of **E2**, the open spacetime index for Earth. Most users should install
[`@embedearth/sdk`](https://www.npmjs.com/package/@embedearth/sdk) instead of
depending on this package directly.

## Install

```bash
npm install @embedearth/regions
```

## Usage

```ts
import { regions } from "@embedearth/regions";
regions.search("New York");
```
